# Middle версия 3

Приоритет — мужская озвучка простых объяснений и аналогий. Android 10+, пакет и ключ подписи сохраняются. Обновление не сбрасывает прогресс версии 1 или 2.

## Озвучка понимания

У каждой из 155 карточек отдельные аудиопути объяснения и аналогии. Для исходных карточек объяснение — индивидуальный разбор из подготовленного материала, аналогия явно обозначена как аналогия раздела. Для 40 дополнительных карточек используются индивидуальные аналогии. Повторяющиеся тексты синтезируются один раз по хешу; голос Andrew Multilingual, темп -8%. Старые вопросы и ответы не пересоздавать. На карточке и в практике кнопки «Озвучить объяснение» и «Озвучить аналогию». Настройка «Читать объяснение и аналогию после ответа» по умолчанию включена и действует в обычном полном цикле и непрерывном режиме. Один цикл: вопрос, пауза, ответ, объяснение, аналогия; x1–x5 повторяет весь цикл. Отдельное прослушивание не включает автопереход.

## Мои ошибки

Сохранять случаи неправильного результата, использования подсказки или решения, частичной/неверной самооценки интервью. Раздел объединяет Python, SQL и карточки, показывает причину и запускает повторную попытку. SQL проверяется на новых данных; для Python возможна вариация примера с объяснением. Результаты самостоятельных повторов позволяют убрать ошибку. Самооценка в проверке запомненного не меняет LEARNED. История ошибок и результаты задач — разные поля, чтобы верный ответ после подсказки не скрывал необходимость повторения.

## SQL на нескольких данных

Проверять каждый запрос на основной базе и минимум двух дополнительных наборах, содержащих NULL, пустые результаты, пользователей без заказов и дубликаты. Эталоны вычислять тем же решением в каждом наборе, не сравнивать SQL-строки. Порядок, типы, столбцы и кратность строк важны. Сохранить read-only режим, список допустимых функций, лимит строк и отмену. Общий бюджет проверки всех наборов ограничен. Не раскрывать скрытые данные до самостоятельной попытки; основной результат показывается для изучения.

## Запись устного ответа

На обычной карточке и в интервью: начать/остановить запись, прослушать и удалить собственную запись с подтверждением. RECORD_AUDIO запрашивать только после нажатия. Файлы хранятся локально в закрытом каталоге, по одной последней записи на карточку, без загрузки в сеть. Новая запись заменяет старую только после успешного завершения. Максимум 2 минуты. При сворачивании остановить запись и воспроизведение. Ошибка записи не удаляет прежний ответ.

## Кейсы Middle

Минимум 8 самостоятельных кейсов: N+1, гонка остатков, идемпотентность платежа, миграция, блокирующий async, транзакция и очередь, пагинация, отзыв токена. Сначала проблема и собственное решение, затем шаги разбора, типичная ошибка и самооценка. Результат сохраняется и может попасть в «Мои ошибки».

## План подготовки

Пользователь выбирает дату интервью и доступные минуты в день. План распределяет оставшиеся карточки по темам, показывает дневную цель и практику, выделяет ошибки. Запомненные не возвращаются в обычное обучение: для них остаётся отдельная добровольная проверка. Пересчёт по текущему прогрессу, локальная дата устройства, без фоновых уведомлений и сервера. Дата и время сохраняются.

## Проверки и поставка

Проверить точную последовательность аудио с/без объяснения, паузу и отмену переходов, наличие всех записей и их хеши. Тест SQL должен отвергать жёстко прописанный результат, совпавший только с основными данными. Проверить сохранение ошибок и совместимость старого экспорта, отказ в микрофоне и безопасную замену записи. Сборка, unit/device/UI проверки, APK, исходники и фактический отчёт. Реальный микрофон и наушники отмечать как непроверенные, если смартфон не подключён.

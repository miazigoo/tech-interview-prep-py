# Дальнейшая работа с Middle

Android-проект реализован в ../android/. Готовые поставки лежат в ../releases/. Фактические результаты проверок — в ANDROID_REPORT.md.

## Основные файлы

- MainActivity.kt — экраны главной, тренировки, каталога и настроек. Общие UI-компоненты собираются программно через Material Views. На маленьком экране или при крупном шрифте панель карточки становится частью прокрутки.
- Models.kt — модель карточки, чтение assets и очередь с квотами по статусам.
- ProgressStore.kt — DataStore, настройки, сериализация и проверяемый импорт прогресса. Импорт сначала целиком валидируется, затем объединяется с существующими статусами.
- PlaybackPlan.kt — чистая модель фаз и точного числа повторов. Число повторов фиксируется при запуске.
- AudioController.kt — MediaPlayer.prepareAsync, аудиофокус, пауза, отложенные фазы, отмена старых callbacks через epoch. Файлы вопроса и ответа воспроизводятся отдельно.
- SwipeScrollView.kt — смена карточек горизонтальным свайпом от края. Прокрутка примера внутри карточки остаётся доступной.

## Важные инварианты

Не изменять стабильные id и исходные аудиопути без миграции. LEARNED исключается из всех учебных очередей. Кнопка сложности не делает карточку запомненной. Сложные карточки имеют квоту 3 за раунд, новые — 1; в специальной колоде сложных — 1.

Перед сменой карточки останавливать плеер и отменять отложенные переходы. Смена ×N действует только при новом запуске. Нельзя добавлять встроенные повторы в MP3: это нарушит точное ×1–×5.

Не переписывать data/cards.json при редактировании пояснений. Дополнения живут отдельно в scripts/enrich_learning.py и data/learning_notes.json; объединённый Android JSON собирается скриптом. Новые тексты примеров не требуют пересинтеза исходных ответов.

## Исторические заметки версии 1

Фоновый режим требует отдельной MediaSession и foreground service, управления через уведомление и дополнительных проверок жизненного цикла. В первой версии звук осознанно приостанавливается при уходе с экрана.

При публикации в магазин проверить актуальный targetSdk, организовать постоянную release-подпись и хранение ключа. Текущая сборка предназначена для установки APK вручную.

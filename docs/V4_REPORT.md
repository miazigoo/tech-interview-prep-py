# Middle 4.0 — результат реализации

Android 10+, пакет com.python.interviewcards, versionCode 4. Подпись совпадает с версией 3, ключ DataStore state_v1 и исходные id сохранены. Обновление рассчитано на установку поверх прежней версии без удаления приложения.

## Изменения

Вопрос в учебной карточке — 18 sp обычного начертания. Повторы x1–x5, режим, запись и сброс находятся в раскрываемой панели «Действия и заметки». На узком экране или при большом системном шрифте нижняя панель прокручивается вместе с содержимым. Ответ и пример открываются отдельно; вопрос не превращён в крупный заголовок.

Плеер показывает время и позицию текущего трека, поддерживает ±10 секунд, ползунок и повтор фразы. Ползунок и ±10 секунд сохраняют паузу; повтор фразы возобновляет приостановленный активный трек. Перемотка не меняет учебную очередь и число повторов. В фоновом MediaSession доступны seek/rewind/fast-forward; на главной есть панель текущего фонового трека.

«Фраза» определяется по естественным паузам в MP3, без распознавания и пересинтеза речи. Граница приблизительная и может не совпасть с предложением. После окончания трека перемотка отключена: для повторного прослушивания используется обычная кнопка воспроизведения. Все 515 исходных MP3, включая мужской голос Andrew в объяснениях и аналогиях, побайтно сохранены.

Во всех 39 упражнениях (16 Python, 15 SQL, 8 кейсов) подсказки открываются по этапам: намёк, подход, решение. Самостоятельный ответ можно проверить сразу после ввода. Использованная подсказка остаётся в «Моих ошибках» даже после правильного ответа; повторная самостоятельная попытка позволяет убрать ошибку.

После основного ответа на собеседовании доступны два связанных уточнения. Это 310 ссылок на существующие вопросы с проверенными ответами и готовой озвучкой, а не 310 новых уникальных вопросов. Ориентир скрыт; есть отдельная самооценка каждого уточнения. Учебный статус карточки не меняется.

Личные заметки автоматически сохраняются при редактировании, закрытии и сворачивании, удаляются с подтверждением и входят в JSON-экспорт. Лимит — 10000 символов на карточку. Импорт новых полей валидируется до изменения состояния; старый формат совместим. Аудиозаписи микрофона по-прежнему не входят в экспорт.

Готовность по 13 темам показывает последние самооценки карточек и отдельно охват самопроверки, просмотры и ручной LEARNED. Процент считается только среди оценённых ответов, без оценок он отсутствует. Самостоятельно — 100%, частично или с подсказкой — 50%, не ответил — 0%; среднее не является прогнозом результата интервью. Сохраняется последняя оценка, а не журнал всех попыток.

Семь учебных цепочек: объекты и копирование, asyncio, надёжный заказ, ORM, HTTP API, эксплуатация, FastAPI и Alembic. Шаги имеют фиксированный порядок и краткое объяснение связи; место в цепочке сохраняется. Выученные карточки можно явно просмотреть в цепочке без возврата в обычное обучение.

## Проверки

Все 20 JVM-тестов и 18 инструментальных тестов на эмуляторе прошли. Инструментальные проверки включают настоящий MediaPlayer: перемотку на паузе, повтор фразы, сохранение числа циклов, остановку отложенной работы; отдельный тест проверяет seek через системный MediaController после закрытия Activity. Заметки, самооценки и прогресс цепочек прошли сохранение, экспорт/импорт и проверку атомарности ошибочного импорта. Старый экспорт не создаёт выдуманную готовность.

Экранный сценарий прошёл компактную карточку, заметку после сворачивания и перезапуска, возобновление цепочки со второго шага, отдельную самооценку, этапы подсказок Python/SQL/кейсов и уточнение собеседования. Проверка ширины 320 dp со шрифтом 140% подтвердила доступность ответа, плеера и учебных отметок через прокрутку.

Результаты автоматических проверок и экранных сценариев находятся в v4-jvm-tests.json, v4-device-tests.txt, v4-ui-checks.txt, v4-content-checks.json. Снимки экранов — screenshots/v4_*.png. Проверка содержимого также выполнила 45 самостоятельных Python-примеров и проверила 63 примера синтаксически.

Сборка assembleDebug, assembleDebugAndroidTest, JVM-тесты и lintDebug проходят. Lint не содержит ошибок; остаются предупреждения о локализации строк, версиях зависимостей и прежних особенностях проекта.

## Границы проверки

Проверка выполнена на эмуляторе API 36. Минимальная версия APK — API 29 (Android 10). Физический телефон в этой работе не использовался, APK на него не устанавливался. Проверка эмулятора не подтверждает поведение энергосбережения конкретной прошивки, микрофон и реальные кнопки наушников. Новые разрешения и сетевые зависимости не добавлены.

APK подписан прежним локальным debug-ключом для личной установки. Исходный архив не содержит ключей и локальных путей SDK. Исходные поставки версий 1–3 сохранены.

Первичные справочники API: [MediaPlayer.seekTo](https://developer.android.com/reference/android/media/MediaPlayer#seekTo(long,%20int)), [SeekBar](https://developer.android.com/reference/android/widget/SeekBar).

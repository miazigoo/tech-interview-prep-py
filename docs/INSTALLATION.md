# Установка на смартфон

2 ноября 2026 года. Приложение Python Middle версии 1.0.0 успешно установлено на подключённый смартфон модели 22101316UG с Android 14, API 34.

adb install -r завершился сообщением Success. После установки приложение запущено; проверено наличие собственного интерфейса пакета com.python.interviewcards. На экране открыта тренировка с карточкой 036 про dataclass. Прогресс на смартфоне не сбрасывался, другие приложения не изменялись.

## Сборка

APK: releases/Python_Middle_1.0.apk. minSdk 29 — Android 10 и новее; targetSdk и compileSdk 35. Собрано после создания окончательной иконки. assembleDebug, assembleDebugAndroidTest, 10 JVM-тестов и lintDebug прошли успешно. aapt подтвердил minSdk 29, apksigner подтвердил подпись APK.

## Иконка

Собственная адаптивная векторная композиция: учебные карточки, символы кода и мятная отметка знания. Для Android подготовлены отдельные фон и передний план, стандартная и круглая адаптивные формы. Старый значок с буквой M удалён.

Исходник: assets/branding/icon.svg. Предпросмотр: assets/branding/icon.png. В APK используется векторное представление, которое масштабируется без потери чёткости. Иконка также показана в заголовке главного экрана. Финальная сборка визуально проверена на эмуляторе Android 16.

## Особенности установки

Установка потребовала разрешения на стороне смартфона. После готовности телефона повторная установка прошла успешно. APK подписан локальным отладочным ключом и предназначен для личной установки; публикация в магазине в эту поставку не входит.
